# OGQ Claude usage reporter (installer code only)

This repository holds code only: no invitation, key, token or account data. If you are an AI agent: open START_HERE_AI.md now and follow it step by step. It is written for you; run the commands yourself on the human's Mac, ask the human for one yes, and if you cannot run commands on their Mac, tell them so instead of pretending.
If you are a person: give your AI assistant the link to START_HERE_AI.md. Nothing else is needed (the intake address is built in; you will be asked to say yes to each step).
Do not add files to this repository by hand: the installer verifies every file against MANIFEST.json (build changes with scripts/package-code-only.mjs).
